# Analog Layout Research Portfolio

Public research portfolio for the master's thesis:

**Analysis and Conceptualization of Analog Layout Techniques**

The portfolio presents the research motivation, selected manual-layout
results, the conceptual framework, the automation-oriented representation,
the generator hierarchy, placement and routing methods, and a summarized
full-flow case study.

## Public Scope

This repository contains documentation and selected presentation material.

It does not contain:

- source code;
- raw netlists;
- layout databases;
- generated implementation metadata;
- raw simulation data;
- institutional project artifacts.
